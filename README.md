 Deaths from US mortality files, provided by NBER https://www.nber.org/research/data/mortality-data-vital-statistics-nchs-multiple-cause-death-data
Deaths are apportioned to cohorts using the procedure in the stata file: deaths_apportioned_2006-2023

Population estimates from SEER, and are available here: https://seer.cancer.gov/popdata/download.html

The population estimates are apportioned to cohorts and then these two are then merged in the stata file: Merging2006-2023
